# 기기 간 동기화 설정 (1회, 약 5분)

1. https://script.google.com 접속 → 새 프로젝트
2. 기본 코드를 지우고 `sync/Code.gs` 내용을 붙여넣기 → 저장
3. 배포 → 새 배포 → 유형: 웹 앱
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
4. 권한 승인(구글 드라이브 접근) → 웹앱 주소(`.../exec`) 복사
5. 어드민 → 설정 → 기기 간 동기화 → 주소 붙여넣기 → 주소 저장
6. 노트북·탭·핸드폰 각각에서 5번 1회 반복

주의
- 웹앱 주소를 아는 사람은 데이터를 읽고 쓸 수 있음. 주소는 외부에 공유하지 않기
- 데이터는 내 드라이브의 `smtm-hq-data.json`에 저장됨
- 두 기기에서 동시에 수정하면 마지막에 저장한 쪽이 남음
